# SonarValidator 최종 버그 검증 계획 (2026-10-10)

## 목적

현재 작업 트리의 백엔드 정책 생성, VLAN 이름/등급 저장, Prober ACL·격리 처리를 실제 dev 스택과 프론트엔드에서 검증한다. 성공 경로뿐 아니라 잘못된 입력, 정책 안전장치, 부분 격리, 해제 후 복구를 확인한다.

## 원칙

- 모든 상태 변경은 프론트엔드 UI에서 수행한다.
- API와 Agent 터미널은 읽기 전용 교차 검증에만 사용한다.
- 관리망 `172.16.255.0/24`은 격리 대상에서 제외한다.
- 격리 테스트는 종료 전에 반드시 해제하고 활성 격리 0건을 확인한다.
- 기존 작업 트리 변경은 수정하거나 되돌리지 않는다.

## 테스트 매트릭스

| 단계 | 검증 항목 | 합격 기준 |
|---|---|---|
| A | dev 스택/인증/CORS | 프론트 200, 백엔드 health UP, 로그인 후 세션 유지 |
| B | 정적·단위 회귀 | 프론트 테스트·빌드 성공, 백엔드 전체 테스트 성공, Prober CTest 성공 |
| C | 화면 회귀 | 주요 라우트가 렌더링되고 pageerror/예상 밖 API 4xx·5xx 없음 |
| D | VLAN CRUD/영속성 | VLAN 131·132·133 Confidential 저장 및 새로고침 후 유지 |
| E | 부정 입력 | 잘못된 CIDR 초안이 거부되고 저장 상태는 훼손되지 않음 |
| F | 정책 안전장치 | Confidential 인터넷 노출을 CRITICAL로 탐지하고 정책 푸시 비활성화 |
| G | 실제 격리 | VLAN 131만 차단, VLAN 132는 통신 유지, Agent ACK applied=true |
| H | 해제/복구 | nft 격리 테이블 제거, VLAN 131 통신 복구, 활성 격리 0건 |
| I | 최종 상태 | 3개 VLAN 등급 유지, 관리망 정상, dev 스택 정상, 증적 저장 |

## 중단 조건

- 관리망 또는 백엔드 접속이 영향을 받는 징후
- 대상 외 VLAN 통신 실패
- 격리 해제 실패 또는 장치 ACK `applied=false`
- 기존 사용자 변경과 충돌하는 파일 쓰기

## 산출물

- 자동 테스트 로그와 합계
- 단계별 전체 화면 및 터미널 스크린샷
- API/Agent 교차 검증 JSON·텍스트
- 발견된 버그 및 재현 조건, 최종 복구 상태
