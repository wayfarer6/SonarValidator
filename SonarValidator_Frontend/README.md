프로덕션 빌드는 npm run build로 실행합니다. 타입 검사와 lint도 현재 package.json 및 CI의 명령을 확인합니다.
UI 개선안은 검토 문서에 정리했으며 이번 작업에서는 앱 UI 소스를 수정하지 않았습니다.
