# 로그·이력·알림

LogController는 조회·필터·요약, ingest·업로드, 플래그, AI 분석과 분석 이력 경로를 제공합니다.
ComplianceController는 전체·프로젝트·Agent별 변경 이력을 제공합니다.
NotificationController는 알림 요약·미확인 목록·읽음 상태 변경과 삭제를 제공합니다.

로그 수집, 정책 변경 이력, 운영자 알림은 목적이 다른 데이터입니다. 하나의 목록으로 합쳐 장비 상태를 추정하지 않습니다.
장비·프로젝트 식별자와 시각을 기준으로 연결해 확인합니다. 로그 AI 분석은 공급자 설정과 별개 실행입니다.
이번 Lab 1의 검증은 Prober 연결·수집과 UI 확인에 한정합니다. AI 분석·격리·정책 푸시는 실행하지 않았습니다.

## 짧은 오류와 상세 보기

화면의 HTTP 오류는 짧은 안내 메시지로 표시합니다. 권한·입력 충돌처럼 짧고 유용한 응답은 유지하고, 서버 내부 오류나 긴 응답은 기본 안내로 줄입니다. 실행 요청의 응답을 확인하지 못한 경우에는 실행 이력을 먼저 확인하도록 안내합니다.

Log Management의 **장비 로그**와 대시보드 최근 로그에는 최대 100자의 한 줄 요약을 표시합니다. 각 행의 **상세 보기**를 누르면 시각·장비·출처·원문을 모달에서 확인할 수 있습니다. 장비 로그 원문은 기존 서버 저장 데이터를 사용합니다.

**요청 오류** 탭에는 이 브라우저 세션에서 실패한 화면 요청을 기록합니다. HTTP 오류, 파일 다운로드·업로드 오류와 AI 작업 실패가 대상입니다. 서버에 연결되지 않는 동안에도 기록을 열 수 있습니다. 목록에서 상세 보기를 누르면 요청 방식·경로·상태와 오류 응답을 확인합니다.

- 최근 100개 기록을 메모리에 보관하며, 같은 요청·응답의 60초 이내 반복은 횟수로 합칩니다. 자동 재시도의 중간 오류는 기록하지 않습니다.
- 새로고침·로그아웃·다른 사용자 로그인 시 세션 기록은 초기화됩니다. 이 기록은 서버의 영구 감사 로그를 대신하지 않습니다.
- 상세 표시 한도는 32,768자이며 한도를 넘으면 생략 표시를 붙입니다. 비밀번호·토큰·쿠키·개인키 등 알려진 비밀 필드는 가립니다. 요청 본문과 인증 헤더는 수집하지 않습니다.
- 원문은 실행되지 않는 텍스트로 표시합니다. 상세 모달은 Esc로 닫을 수 있고, 중첩 모달에서는 가장 위의 모달만 닫으며 이전 버튼으로 포커스를 돌려줍니다.

실제 화면 회귀는 기존 `bug_regressions.robot`의 B04에서 검사하고 요약/상세 스크린샷과 동영상을 기록합니다.
