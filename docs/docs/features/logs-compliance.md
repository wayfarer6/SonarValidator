# 로그·이력·알림

LogController는 조회·필터·요약, ingest·업로드, 플래그, AI 분석과 분석 이력 경로를 제공합니다.
ComplianceController는 전체·프로젝트·Agent별 변경 이력을 제공합니다.
NotificationController는 알림 요약·미확인 목록·읽음 상태 변경과 삭제를 제공합니다.

로그 수집, 정책 변경 이력, 운영자 알림은 목적이 다른 데이터입니다. 하나의 목록으로 합쳐 장비 상태를 추정하지 않습니다.
장비·프로젝트 식별자와 시각을 기준으로 연결해 확인합니다. 로그 AI 분석은 공급자 설정과 별개 실행입니다.
이번 Lab 1의 검증은 Prober 연결·수집과 UI 확인에 한정합니다. AI 분석·격리·정책 푸시는 실행하지 않았습니다.
