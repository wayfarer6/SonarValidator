# 네트워크 시험 환경

| Lab | 관리 대역 | 데이터 대역과 경계 |
| --- | --- | --- |
| 1 | 192.168.144.0/20 | Cisco 두 대의 10.10.20.0/24, R1 Gi3 인터넷 NAT |
| 2 | 192.168.150.0/24 | Cisco·OPNsense 전송망 10.20.0.0/30, Arista VLAN20 10.20.20.0/24 |
| 3 | 192.168.151.0/24 | OPNsense 뒤 10.30.10.0/24와 10.30.20.0/24 |
| 4 | 192.168.152.0/24 | FRR·OVS VLAN40 10.40.40.0/24 |

현재 IP·SSH 대상·프로젝트·GNS3 노드의 실행 기준은 tests/labs/inventory.json입니다. [주요 기능 시나리오](labs-1-4.md)에서 장비별 수집과 통신 기대값을 확인합니다. Lab1 GuestShell 내부 IP가 같아도 각각의 관리 NAT 주소로 구분합니다. Lab3의 관리망에는 방화벽만 연결합니다.

BDD 등급 비교와 JSON 출력은 임시 프로젝트에서 시험합니다. 실제 장비에 정책을 푸시하거나 포트를 내리지 않습니다. 실제 NAT·방화벽·VLAN 경로는 별도 통신 검사로 기록합니다.

과거 PoC의 IP 명령과 자격증명은 현재 초기 설정에 사용하지 않습니다. 원본은 Git 이력에서 확인할 수 있습니다.
