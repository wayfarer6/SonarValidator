# Lab 1 UI 검토와 구현 결과

실제 Lab1 `PRJ-86F69C4D`와 임시 회귀 프로젝트를 WSL Chromium에서 시험합니다. 초기 조회/모달 검토에 더해 현재는 격리/해제와 자동 토폴로지 갱신을 별도 Robot 시나리오로 검증합니다.

| 관찰한 문제 | 현재 구현 |
| --- | --- |
| 서브넷 표가 절반 폭에 들어가 값이 잘림 | 전체 폭·가로 스크롤·드롭다운 최소 폭 확보 |
| 행마다 UUID 체크박스가 반복됨 | 노드별 연결 관리 모달, 이름·CIDR 허용 대상 드롭다운 |
| 빈 허용 목록의 의미가 불분명함 | 제한 없음/선택 대상만 허용 표시, 마지막 대상 삭제 확인 |
| 관리망·전송망 역할과 CSO가 혼동됨 | 별도 network_role 저장, 역할·CSO 드롭다운 분리 |
| 장비 IP에 관리 서버 IP가 등록됨 | 장비 관리 IP 입력 분리 |
| 번들에 관리 대역이 누락됨 | 프로젝트 관리 대역을 MANAGEMENT_PREFIX로 생성 |
| IOS 인터페이스가 /32로 수집됨 | 동일 인터페이스의 connected route로만 prefix 보완; 근거 없는 마스크 추정 금지 |
| 자동 수집을 Open 등급으로 간주함 | 신규·기존 미확인 자동 Open을 미분류로 유지, 수동 등급 보존 |
| 웹 터미널의 중복 연결·모호한 오류 | StrictMode 정리 시 연결 취소, 오프라인/다른 브라우저 점유 오류 구분 |

## 남은 개선

수집 상태·초안·검증·장비 적용 결과를 한 흐름에서 비교하는 상태 요약이 필요합니다. 현재 저장과 장비 적용은 구분하지만 전체 진행 상태를 통합하지 않았습니다.

대규모 프로젝트의 허용 대상 검색, 공통 SSH/API 자격증명 관리, 프로토콜·포트 편집 통합은 후속 범위입니다. 현재 모달은 서브넷 단위 허용 목록을 편집합니다. 관리망 영향 자동 경고와 전체 차단은 데이터 모델·검증 규칙을 함께 설계해야 합니다.

R1 Guest Shell의 sudo/PAM 오류는 장비 환경 문제로 남아 있습니다. [배포 문서](../deployment/lab1.md)에 실제 설치 방식과 한계를 기록합니다. [Robot 시나리오](../testing/robot-ui.md)는 실제 Lab 조회·취소와 임시 프로젝트 저장 시험을 구분합니다.

## 격리 화면과 다이어그램 가독성

범위 드롭다운의 기본값은 미선택입니다. 장치 IPv4 통신(관리 유지)과 특정 서브넷을 구분하며, 선택하기 전 요청 버튼은 비활성화합니다. 요청 대기/확인/실패와 해제 재시도를 표시합니다. Agent 행에는 소속 프로젝트 링크를 유지하고 상세 설정은 모달로 엽니다.

토폴로지는 SVG 원래 크기보다 초기 확대하지 않으며 가로 폭과 최대 높이에 맞춥니다. 긴 세로 그래프 때문에 전체 페이지가 수천 px로 늘어나는 문제를 수정했습니다. 확대/이동은 사용자가 선택합니다. 미분류는 회색, 오프라인/오래된 관측은 이전 상태 표기, 적용 확인은 빨간색으로 구분합니다. ID와 라벨을 escape하여 이름의 특수문자 때문에 그림이 합쳐지거나 깨지지 않게 합니다.

남은 개선은 큰 프로젝트의 검색, 상태 요약 통합, 일부 화면의 영어/한국어 용어 통일입니다. 이번 수정으로 전체 UI의 모든 가독성 문제를 없앴다는 뜻은 아닙니다.

프로젝트 목록 아래쪽의 터미널은 사용자가 추가로 스크롤해야 할 수 있습니다. 발표 녹화는 해당 노드 영역을 캡처한 뒤 갱신 중 세션 유지와 정상 종료를 검사합니다. 자동 스크롤·전체 화면 터미널, 작은 화면에서의 모달/표 배치는 후속 가독성 개선 항목입니다.
