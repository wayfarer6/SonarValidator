# 프로젝트 편집 흐름

프로젝트의 노드별 **연결 관리** 버튼을 누르면 해당 Agent의 서브넷 편집 모달이 열립니다. 온라인 여부와 장비 관리 IP, Prober가 연결하는 관리 서버 주소를 구분합니다. 오프라인 노드도 초안을 편집할 수 있습니다.

서브넷 선택 → 이름·CIDR 확인 → 네트워크 역할·CSO 등급 선택 → 허용 대상 추가 → 변경 저장 순서입니다. 역할은 MANAGEMENT·TRANSIT·SERVICE·GUEST·INTERNET이며, CSO 등급과 독립적으로 저장됩니다. 자동 수집 서브넷은 미분류 상태를 유지합니다.

허용 대상 드롭다운은 이름과 CIDR을 표시합니다. `allowed_peers=[]`는 제한 없음입니다. 대상을 선택하면 선택한 대상만 허용하며, 마지막 대상 삭제에는 확인을 받습니다. 모두 차단 모드는 현재 모델에서 지원하지 않습니다. 방향·프로토콜·포트는 기존 규칙 편집기를 사용합니다.

노드 모달은 변경한 행만 최신 프로젝트에 병합해 저장합니다. 취소하면 초안을 버리고, 저장해도 장비에 정책을 푸시하지 않습니다. 프로젝트 전체 편집의 서브넷 표는 전체 폭으로 배치하며, 행의 연결 관리에서 편집한 내용은 프로젝트 초안에 반영한 뒤 프로젝트 저장으로 확정합니다.

배포 카드의 장비 관리 IP는 Agent 등록의 `expected_ip`에 사용하고, 관리 서버 주소는 Prober의 목적지에 사용합니다. [검토 결과와 남은 개선](lab1-review.md), [자동 UI 시나리오](../testing/robot-ui.md)를 참고하세요.
